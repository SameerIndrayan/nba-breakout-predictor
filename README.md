# NBA Breakout Season Detector

trying to predict next nba players to breakout using prior season stats.
will output a score on likeliness to be a breakout


---

## breakout def




how to define breakout:
age ≤ 26
played ≥ 30 games
ppg increase: 5+
relative scoring inc: 40% + 
min inc: 3+
TS%: did not drop by more than 2%


players who match this def:
sga first jump, maxey, jaylen brown, jordan poole, brunson, NAW,

from 2006-2026 it labels 239 as breakout szns out of 8355 (2.9%)


---

## Project structure

```
nba-breakout-predictor/
├── src/
│   ├── collect.py     # pulls per-game + adv stats from nba_api → data/player_stats_all_seasons.csv
│   ├── features.py    # builds year-over-year transitions, deltas, per-36 stats → data/labeled_transitions.csv
│   ├── model.py       # temp train/test split + logistic regression, prints metrics & top predictions
│   └── analysis.py    # (planned) predict breakout candidates for the upcoming season
├── notebooks/
│   └── explore.ipynb  # scratch exploration
├── data/              # generated CSVs (gitignored — regenerated by the pipeline, see below)
├── requirements.txt
└── README.md
```

> **Note:** `data/` is intentionally **not** committed. csv are build artifacts 
> regenerate them by running the pipeline (the "from scratch" path). See below.


---

## Usage

Run the three scripts **in order, from the repository root** (the paths are relative, so
running them from inside `src/` will fail):

run scripts in this order: 
collect (pulls 21 sznz from nba api), features (builds transitions + labels), model (trains models)
